# AGRAV games

A platform for small multiplayer browser games: one authoritative Node.js server that
hosts many rooms of many games at once, a `shared/` simulation and protocol layer that the
server and the browser both import unchanged, and one three.js PWA client per game.

The first game is **AGRAV**, a 12-player anti-gravity combat racer.

See the per-folder READMEs and the deploy runbook once they land.
